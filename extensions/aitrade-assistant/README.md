# AITrade 跨境实战助手（Amazon + 1688 二合一）

一个扩展同时覆盖 **Amazon 竞品采集** 与 **1688 工厂采集**，并支持配置任意 AITrade 服务地址（本机 `http://localhost:3000` 或团队共享服务器地址）。

## 安装方式
1. Chrome 地址栏打开 `chrome://extensions`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本目录 `extensions/aitrade-assistant/`

## 使用方式
- 打开任意 Amazon 详情页 (`/dp/`) 或搜索页 (`/s?k=...`)，点击扩展图标即可一键抓取并直达 AITrade 竞品研报。
- 打开任意 1688 搜索页，点击扩展图标填入目标假设 ID，即可一键抓取可见工厂与报价卡片。
