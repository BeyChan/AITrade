# AITrade 跨境实战助手（选品 + 1688 寻源 + 半自动上架三合一）

一个扩展同时覆盖 **竞品采集 / 自动选品池推送**、**1688 工厂采集** 与 **多平台可配置半自动上架填表**，并支持配置任意 AITrade 服务地址（本机 `http://localhost:1688` 或团队共享服务器地址）。

## 安装方式
1. Chrome 地址栏打开 `chrome://extensions`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本目录 `extensions/aitrade-assistant/`

## 使用方式
- **自动选品池推送**：打开任意 Amazon 搜索页 (`/s?k=...`)，点击「推送到自动选品池」即可将整页真实样本直接送入 `/auto-pipeline` 自动快筛、反推 18% 采购天花板并完成 S/A/B 分级。
- **竞品研报采集**：打开 Amazon 详情页 (`/dp/`) 或搜索页，点击采集即可生成竞品研报或加入对比篮子。
- **1688 工厂采集**：打开任意 1688 搜索页，选择目标商品或研报，一键采集可见工厂与人民币报价。
- **多平台半自动上架填表**：在浏览器登录 Amazon Seller Central / Shopify Admin / TikTok Shop Seller 添加商品页后，选择目标平台与已通过人工内容终审的商品案卷，点击「拉取已终审文案并填入当前后台页」。扩展自动填入核心字段并在右下角弹出悬浮复制助手，其余属性与主图由人工确认上传后点击发布。
