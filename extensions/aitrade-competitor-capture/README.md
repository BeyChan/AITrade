# AITrade 亚马逊竞品一键采集 Chrome 扩展

在亚马逊前台（US、AU、UK、DE、JP、CA、SG）商品详情页或搜索结果页，用户手动触发一键提取真实商品数据，直接送入本地 AITrade 竞品对比与市场格局工作台（零后台爬虫、不自动翻页）。

## 支持的两种采集模式

1. **单品详情页（`/dp/...`）**：提取真实面包屑类目、ASIN、品牌、标题、售价、评分、评论数、五点描述和买家差评。
2. **搜索结果页（`/s?k=...`）**：批量提取当前页可见竞品卡片（最多 Top 20），一键导入生成市场格局四象限图与价格带分位。

## 安装方式

1. 打开 Chrome 浏览器，进入扩展管理页：`chrome://extensions/`
2. 开启右上角的 **“开发者模式” (Developer mode)**。
3. 点击左上角 **“加载已解压的扩展程序” (Load unpacked)**。
4. 选择当前项目的扩展目录：`extensions/aitrade-competitor-capture/`。
5. 建议在工具栏将扩展固定（Pin），方便随时点击。

## 使用流程

1. 确保本地 AITrade 服务已运行在 `http://localhost:3000`（执行 `npm run dev`）。
2. 在浏览器中打开任意亚马逊商品详情页（如 `https://www.amazon.com/dp/...`）或搜索结果页（如 `https://www.amazon.com/s?k=...`）。
3. 点击浏览器右上角扩展栏的 **AITrade 竞品采集** 图标。
4. 在弹窗中预览提取到的真实字段（单品页显示类目/标题/售价/评分/差评条数；搜索页显示搜索词与可见商品清单）。
5. 点击推送按钮（单品页为 **送入 AITrade 竞品对比**，搜索页为 **一键导入 N 款竞品生成格局图**），完成后会自动在新标签页打开对应研报；也可点击复制按钮手动粘贴到 AITrade 输入框。
