# AITrade 1688 供应商采集扩展

这是用户点击才运行的 Chrome Manifest V3 扩展。它只读取当前 1688 搜索结果页已经显示的 `/offer/数字.html` 商品卡，不会后台抓取、自动翻页、登录、绕过验证码或联系供应商。

## 本地安装

1. 在 Chrome 打开 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录。

## 使用

1. 在 AITrade 的选品方向中点击“开始找供应商”。
2. 在“Chrome 一键采集”卡片点击“复制扩展配置”。
3. 打开扩展，把配置粘贴到文本框，点击“保存配置”。
4. 打开对应 1688 搜索结果页。
5. 点击扩展，再点“采集当前页并导入 AITrade”。

扩展会把候选写入现有供应商候选池，按确定性规则去重和评分，并打开对应 AITrade 方向。候选仍需人工核验后才能进入短名单。
